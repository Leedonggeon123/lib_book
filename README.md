# 도서관 대여 관리 프로그램 (1조 라이브 북)

PySide6(Qt)로 만든 GUI 도서관 프로그램입니다. 로그인 후 권한(관리자 / 사서 / 일반 회원)에 따라 도서 대여, 반납, 연장, 도서·회원 관리를 할 수 있습니다.

## 주요 기능
- 회원가입 / 로그인: 아이디 중복 검사, 입력 형식 검사(아이디·이름·전화번호·주민번호·이메일), 회원 정보 수정
- 도서 대여: 도서 목록 조회, 상세 정보 보기, 여러 권 선택 대여 (대여 기간 7일)
- 대여 확인: 내 대여 목록 확인, 반납, 대여 연장
- 회원 등급별 혜택: 일반 / 우수 / VIP 등급별로 최대 대여 권수와 최대 연장 일수가 다름
  - 일반: 최대 6권, 연장 7일 / 우수: 10권, 14일 / VIP: 15권, 28일
- 도서 관리(관리자·사서): 도서 추가, 수정, 삭제(삭제는 관리자만), 검색
- 회원 관리(관리자): 회원 추가, 수정, 삭제
- 전체 대여 목록(관리자·사서): 전체 대여 현황 조회, 검색, 강제 반납(관리자)
- 배경 음악, 버튼 클릭음, 메인 화면 애니메이션

## 사용 기술
- Python 3, PySide6 (Qt Designer로 화면 구성, `.ui` 파일 사용)
- 데이터 저장: pickle 파일(`data/book.pkl`, `data/user.pkl`, `data/rent.pkl`)과 JSON 변환 사용
- 도서 데이터 2,400여 권

## 권한 구분
| 구분 | 할 수 있는 일 |
|---|---|
| 관리자 | 도서 삭제, 회원 관리, 강제 반납 (대여는 불가) |
| 사서 | 도서 추가·수정, 대여 현황 조회, 대여 기간 연장 제한 없음 |
| 일반 회원 | 도서 대여·반납·연장, 내 대여 현황 확인 |

## 실행 방법
1. 필요한 라이브러리를 설치합니다.
   ```
   pip install PySide6
   ```
2. 프로젝트 폴더에서 `main.py`를 실행합니다.
   ```
   python main.py
   ```
3. 테스트 계정으로 로그인합니다. 

## 개발 방식
팀 프로젝트(1조)로 개발했습니다.
내가 맡은 부분: 【도서 대여, 대여 확인】
